# EUROTOUR — полный чертёж сайта (как повторить 1-в-1)

> Документ описывает **что** сделано, **как** это устроено и **какими данными** наполнено, чтобы воспроизвести такой же сайт с тем же функционалом, ценами и модулями. Технический разбор файлов — в `SITE_SPEC.md`; здесь — «рецепт».
> Живой сайт: http://eurotour.pp.ua · репозиторий: `Pashawilliams/site` (GitHub Pages).

---

## 0. Идея в одном абзаце

Статический сайт (HTML + CSS + чистый JS, без сборки, без сервера, без БД) для пассажирских перевозок Украина ⇄ Европа. Хостинг — GitHub Pages, деплой автоматически при push. Весь контент (маршруты, цены, отзывы, FAQ, менеджеры, контакты) лежит в одном файле `data/site.json` и редактируется через **Telegram-бота-админку**, который сам коммитит изменения в репозиторий. Формы и онлайн-чат работают **без бэкенда**: сайт шлёт события в бесплатный pub/sub-сервис **ntfy.sh**, бот их читает и пересылает админу в Telegram; ответы админа идут обратно на сайт тем же каналом. Цены считаются автоматически из **времени в пути** (OSRM/OpenStreetMap) по фиксированной тарифной сетке в евро и показываются в гривнах по курсу НБУ.

## 1. Стек и инфраструктура

| Компонент | Решение | Стоимость |
|---|---|---|
| Хостинг сайта | GitHub Pages (ветка `main`, корень репо) | 0 |
| Деплой | GitHub Actions `deploy.yml` (upload-pages-artifact → deploy-pages), триггер: push в `main` кроме `bot/state.json` | 0 |
| Админ-панель | Telegram-бот на Python 3.12 (long-polling), запускается GitHub Actions `bot.yml` | 0 |
| «Бесконечная» работа бота | джоб живёт 5 ч 20 мин (`MAX_RUNTIME=19200`), в конце сам запускает `gh workflow run bot.yml`; cron `*/30` — сторож; `concurrency` + guard-step против дублей | 0 |
| Хранение данных | `data/site.json` (контент) и `bot/state.json` (заявки, чаты, админы) — бот пишет через GitHub Contents API | 0 |
| Формы/чат → Telegram | ntfy.sh, топик-«почтовый ящик» с секретным именем; бот подписан через `/json` (стрим) | 0 |
| Telegram → сайт | ntfy.sh, топик ответа `<inbox>-r-<sid>` на каждого посетителя; сайт слушает через EventSource `/sse` | 0 |
| Время в пути | OSRM public API (`router.project-osrm.org`) + координаты городов | 0 |
| Курс €→₴ | API НБУ `bank.gov.ua/NBUStatService/v1/statdirectory/exchange?valcode=EUR&json` | 0 |
| Домен | `eurotour.pp.ua` (NIC.UA), A-записи на IP GitHub Pages, `www` CNAME → `<user>.github.io.`, файл `CNAME` в корне | домен |

**Секреты GitHub (Settings → Secrets → Actions):** `BOT_TOKEN` (токен бота от @BotFather), `ADMIN_ID` (числовой Telegram id владельца), `GH_PAT` (personal access token с правом `repo`, бот им коммитит).

## 3. Страница index.html — секции сверху вниз

На мобильных — бургер с полноэкранным меню.

4. **Форма поиска рейса**: селект «Звідки» (Украина) ⇄ селект «Куди» (Европа) с кнопкой обмена, дата (кастомный календарь, мин. завтра), переключатель времени **08:00 Comfort / 18:00 Lux**, переключатель класса **Comfort / Lux**, кнопки «Знайти рейс», «Показати всі». 7. **Максимальний комфорт під час поїздки**: 10 плиток преимуществ (7 пасажирських місць, Wi-Fi, зарядки, клімат-контроль, 2 водії, чай/кава, прямий рейс, пледи/подушки, адреса→адреса, без доплат) + коллаж фото.
8. **Забронюйте свій рейс разом з нами**: форма «Зв'язатися з менеджером» (ПІБ, код країны +380, телефон).
9. **Відгуки наших клієнтів**: слайдер, 3 отзыва (аватар-буква, имя, 5 звёзд, дата), редактируются в боте.
10. **FAQ**: аккордеон, 5 вопросов (документы, дети, животные, продукты, время на границе).
11. **SEO-тексты**: «Приватні перевезення з України до Польщі», «У чому переваги…», «Чому варто…».
12. **Контакти**: 4 карточки — Telegram, WhatsApp, Телефон, «Чат на сайті» (открывает чат); блок **Наші менеджери** (карточки из site.json, у каждого свои кнопки Дзвінок / Telegram / WhatsApp); график «Щодня, цілодобово», языки, оплата.
13. **Футер**: логотип, ссылки, соцкнопки, телефон, «Політика конфіденційності», «Публічна оферта» (открываются попапом).

## 5. Ценообразование (js/pricing.js + бот «💶 Ціни»)

### Формула
```
часы_в_пути = часы_OSRM(from → to) + extra_hours(3)          // границы, посадка
если пары нет в durations → оценка: haversine_км × 1.25 / 78 км/ч + 3
тариф_€ = строка таблицы tiers, где нижняя ≤ часы < верхняя  → [comfort_€, lux_€]
цена_₴ = округление_до_50( тариф_€ × eur_rate )
```
На сайте показываются **только гривны** («від 7 750 грн»), евро — маленьким чипом-обоснованием.

### Тарифная таблица (`pricing.tiers`: [от_ч, до_ч, Comfort €, Lux €])
| Часы | Comfort | Lux | | Часы | Comfort | Lux |
|---|---|---|---|---|---|---|
| 6–8 | 90 | 120 | | 24–27 | 190 | 230 |
| 8–10 | 100 | 140 | | 27–30 | 200 | 240 |
| 10–12 | 130 | 170 | | 30–33 | 210 | 250 |
| 12–14 | 140 | 180 | | 33–36 | 210 | 250 |
| 14–16 | 150 | 190 | | 36–39 | 220 | 260 |
| 16–18 | 160 | 200 | | 39–42 | 230 | 270 |
| 18–20 | 160 | 200 | | 42–45 | 240 | 280 |
| 20–22 | 170 | 210 | | 45+ | 250+ | 290+ |
| 22–24 | 180 | 220 | | | | |

Прочие параметры: `eur_rate` (авто с НБУ, `rate_auto: true`, можно задать вручную), `extra_hours: 3`, `discounts: [Пенсіонерам −10%, Дітям −15%]` (показываются как бейджи; применяет менеджер).

### Классы и время выезда
- **Comfort — только 08:00**, **Lux — только 18:00**. Переключатели класса и времени связаны в обе стороны (поиск, блок маршрутов, форма бронирования). Выбор класса хранится в `localStorage` (`et_cls`).
- Примеры: Київ→Варшава 11.1 + 3 = 14.1 ч → Comfort €150 = 7 750 ₴, Lux €190 = 9 850 ₴; Львів→Варшава 8.7 ч → €100 = 5 200 ₴; Київ→Мілан 28.2 ч → Lux €240 = 12 450 ₴.

### Где отображается
Карточки маршрутов, бегущая строка, результат поиска, мобильный док («від 4 650 грн» = минимальная цена), сводка в попапе бронирования; в заявку добавляются скрытые поля `et-class`, `et-travel-time`, `et-route-price`.

### Управление из бота (💶 Ціни)
Курс (авто НБУ / вручную) · надбавка часов · скидки · редактирование всей таблицы тарифов текстом · «Перерахувати маршрути» (все/новые) — бот сам ходит в OSRM в фоне и пишет `durations` в site.json. При добавлении маршрута «Місто - Місто» время считается автоматически (координаты городов зашиты в `CITY_COORDS`, есть геокодер-фолбэк Nominatim).

## 6. Формы → Telegram (без сервера)

1. `js/local-forms.js` перехватывает submit всех форм, валидирует (имя, телефон с маской `+380`, дата ≥ завтра, согласие с офертой), собирает поля + контекст (страница, маршрут поиска, класс, время, цена, UA, язык).
2. `js/site-bridge.js` публикует JSON в `https://ntfy.sh/<inbox>` (`POST`, заголовок `Title: lead`).
3. Бот (подписан на `https://ntfy.sh/<inbox>/json`) получает событие `kind: lead`, сохраняет в `state.leads`, шлёт админам карточку «🎫 Бронювання рейсу / 📞 Зворотний дзвінок / 📦 Посилка / …» с кнопками (виконано, звʼязатись, Telegram/WhatsApp клиента).
4. Пользователю показывается тост «Заявку відправлено» и предлагается открыть чат.

Тип заявок (`KINDS` в боте): booking, manager, callback, payment, delivery, transfer, review.

## 7. Онлайн-чат (chat.html + js/chat-app.js + бот)

**Клиент**: отдельная страница `chat.html` (открывается кнопкой чата, из карточки «Чат на сайті», из тоста после заявки). Тёмная градиентная тема в стиле мессенджера: пузыри с хвостиками, время и галочки ✓/✓✓ внутри, группировка сообщений, ярлыки дат, «менеджер друкує…», статус «Менеджер X приєднався», отправка **фото/файлов** (до 2 МБ, drag-and-drop, вставка из буфера, лайтбокс), быстрые кнопки (Забронювати / Ціна / Посилка / Трансфер), имя посетителя, меню (Telegram, змінити імʼя, завершити діалог, очистити історію), кнопка «Закрити чат» и «назад». История — в `localStorage`, `sid` посетителя постоянный. Поле ввода закреплено над клавиатурой через `visualViewport`.

**Протокол через ntfy**
- сайт → бот (топик `<inbox>`): `chat`, `chat_typing`, `chat_open`, `chat_name`, `chat_end`, `lead`; файлы — `PUT` с телом-файлом и заголовком `Message` (RFC2047 base64 JSON).
- бот → сайт (топик `<inbox>-r-<sid>`): `{text, by}`, `{typing}`, `{seen}`, `{joined: name}`, `{ended}`, вложения (ntfy attachment URL).

**Админ в Telegram**: каждое новое сообщение приходит с кнопками **«Почати діалог»** и **«Завершити діалог»**. После «Почати діалог» включается **режим диалога**: клиент видит «Менеджер X приєднався до чату», все обычные текстовые сообщения и фото/документы админа уходят клиенту, а сообщения клиента приходят админу простым текстом (без кнопок). Выход — кнопка «⏹ Завершити діалог» в меню или `/end`. Список чатов — «💬 Чати» (открытые/закрытые, история, имя, страница).

## 8. Telegram-бот-админка (bot/bot.py)

- Доступ: только `ADMIN_ID` + добавленные админы (`state.admins`). Меню `/menu`.
- Разделы: **📥 Заявки** (список, done, фильтр) · **💬 Чати** · **🛣 Маршрути** (список с ценой/часами, добавить «Місто - Місто», скрыть/показать, удалить, порядок) · **💶 Ціни** (§5) · **⭐ Відгуки** (добавить/редактировать/удалить) · **❓ FAQ** · **🏠 Головна** (заголовок/подзаголовок) · **👤 Менеджери** (имя, телефон, должность, Telegram, WhatsApp) · **📢 Оголошення** (полоса на сайте) · **🔴/🟢 Техроботи** · **👥 Адміни** · **📊 Журнал** · **🌐 Сайт**.
- Любое изменение → `PUT /repos/<repo>/contents/data/site.json` (коммит `admin-bot: site.json`) → деплой ~2 мин. `state.json` коммитится отдельно и исключён из триггера деплоя.
- Реализация: `urllib` long-polling `getUpdates`, ntfy-стрим в отдельном потоке с авто-reconnect, OSRM/NBU запросы в фоновых потоках, `MAX_RUNTIME` → корректный выход и самоперезапуск.

## 10. Как поднять копию за 10 шагов

1. Создать репозиторий на GitHub, залить все файлы; Settings → Pages → Source: GitHub Actions.
2. Создать бота в @BotFather, узнать свой Telegram id (@userinfobot).
3. Создать PAT (classic, scope `repo`). Добавить секреты `BOT_TOKEN`, `ADMIN_ID`, `GH_PAT`.
4. В `data/site.json → bridge.inbox` придумать новый случайный топик (например `xx-inbox-<32 символа>`); тот же inbox продублирован в `chat.html` (`window.__SITE_BRIDGE`) и читается ботом из site.json.
5. Поменять контакты/менеджеров/маршруты/отзывы/FAQ в `site.json` (или позже через бота).
6. Запустить `bot.yml` вручную (Actions → Telegram admin bot → Run workflow). В боте: 💶 Ціни → Перерахувати маршрути (заполнит `durations`), курс — авто.
7. Push → деплой; проверить `https://<user>.github.io/<repo>/` или домен.
8. Домен: A `@` → 185.199.108.153 / 109.153 / 110.153 / 111.153; CNAME `www` → `<user>.github.io.` (с точкой); файл `CNAME` с доменом; в Pages вписать домен, дождаться сертификата, включить Enforce HTTPS.
9. Проверить цепочку: заявка с сайта → карточка в боте; чат → «Почати діалог» → ответ появляется на сайте; фото в обе стороны.
10. Отозвать/обновить PAT при необходимости; бот перезапускается сам каждые 5 ч 20 мин.

## 11. Известные ограничения

- ntfy.sh бесплатный: вложения ≤ 2 МБ и хранятся ~3 ч; ~250 сообщений/час с IP; сообщения в топике живут ~12 ч (история чата у клиента — в браузере, у админа — в `state.json`).
- Публичный OSRM без SLA — поэтому времена кэшируются в `durations`, пересчёт по кнопке.
- GitHub Pages — только статика: любая «серверная» логика живёт в боте.
- Сертификат GitHub Pages выпускается автоматически только при корректном DNS (частая ошибка — CNAME без точки на конце).
