# Eurotour — сайт (тёмная тема)

Статическая копия главной страницы eurotour.online с тёмной темой и улучшениями.

- `index.html` — главная страница
- `css/dark-theme.css` — тёмная тема (подключается последней)
- `js/theme.js` — переключатель темы (тёмная/светлая, запоминается), анимации появления, кнопка «наверх»
- `_archive/` — оригинальный zip-архив

Деплой: GitHub Actions → GitHub Pages (`.github/workflows/deploy.yml`).
