# Eurotour — сайт (тёмная тема)

Статический сайт пассажирских перевозок Украина – Европа.

- `index.html` — главная страница
- `css/site-base.css` — базовые стили контактов/карточек (не зависят от темы)
- `css/dark-theme.css` — тёмная тема (по умолчанию), отключается переключателем
- `js/theme.js` — переключатель темы, анимации, кнопка «наверх», структура карточек
- `_archive/` — исходный zip-архив
